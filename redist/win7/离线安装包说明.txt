================================================================================
  Windows 7 内网离线运行库 — 说明
  （已按 32 位 / 64 位 分目录，可直接 U 盘拷入内网）
================================================================================

【目标】消除启动时 “api-ms-win-core-sysinfo-l1-2-0.dll 缺失” 等 UCRT 弹窗。

【目录结构】（本仓库 redist\win7 下已备齐，无需再上网下载）

  redist\win7\
    x64\                                    ← 64 位 Win7 使用
      Windows6.1-KB2999226-x64.msu          （必装，UCRT）
      Windows6.1-KB3118401-x64.msu          （建议，KB2999226 失败时先装）
      vc_redist.x64.exe                     （必装，VC++ 2015–2022）
    x86\                                    ← 32 位 Win7 使用
      Windows6.1-KB2999226-x86.msu
      Windows6.1-KB3118401-x86.msu
      vc_redist.x86.exe
    离线安装包说明.txt                      （本文件）
    文件清单.txt                            （SHA256 校验）

【Win7 前提】
  - 已安装 Windows 7 Service Pack 1（SP1）
  - 未装 SP1 时需单独准备离线 SP1（本包不包含）

【外网打「内网部署包」（推荐）】

  1. 按下方「外网准备离线文件」把 x64\x86 三个文件放入本目录。
  2. （WPF 版）可选：将 ndp48-x86-x64-allos-enu.exe 放入 ndp48\ 子目录。
  3. 在仓库根目录运行：打包_Win7内网部署包.bat
  4. 将生成的 release\Win7内网部署包\ 整文件夹 U 盘拷入内网。

【内网安装步骤】（全程无需联网）

  1. 保持目录结构不变（exe、win7_安装运行库.bat、redist\win7\ 在同一层）。
  2. 右键 win7_安装运行库.bat → 以管理员身份运行 → 输入 Y。
  3. 脚本自动识别 32/64 位，只安装 redist\win7\x64 或 x86 中对应文件。
  4. 若提示重启则重启，再运行 Excel表格拆分工具.exe。

  说明：安装使用 wusa.exe 与 vc_redist 本地静默安装，不访问 Windows Update 或互联网。

【仅部署一种架构时】

  - 内网全是 64 位机：可只拷 x64\ 三个文件 + bat + 说明。
  - 内网全是 32 位机：可只拷 x86\ 三个文件 + bat + 说明。

【外网重新下载（仅当需更新时）】

  VC++ 运行库：
    64 位 https://aka.ms/vs/17/release/vc_redist.x64.exe
    32 位 https://aka.ms/vs/17/release/vc_redist.x86.exe

  KB 补丁：Microsoft Update Catalog 搜索 KB2999226 / KB3118401

【.NET Framework 4.8】（仅 WPF 打包的 exe）

  - Python 版 exe 不需要 .NET。
  - WPF 版需 Win7 上安装 .NET 4.8；可将离线安装包放入 ndp48\ 目录，
    运行 win7_安装运行库.bat 时会一并安装。详见 ndp48\离线安装说明.txt。

【外网准备离线文件】（内网电脑无法下载，须在外网先放好）

  每个架构目录各 3 个文件，例如 x64\：
    Windows6.1-KB2999226-x64.msu
    Windows6.1-KB3118401-x64.msu   （建议）
    vc_redist.x64.exe

【注意】
  - 安装包约 41 MB（x64+x86），未纳入 Git，外网下载后提交到 redist\win7\ 再打部署包。
  - 拷贝到内网后可用 文件清单.txt 中的 SHA256 校验完整性。
  - 若程序能正常使用仅偶发弹窗，可不安装；安装后可去掉启动弹窗。
