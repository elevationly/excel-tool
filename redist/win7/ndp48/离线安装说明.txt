================================================================================
  .NET Framework 4.8 离线安装包（WPF 版 exe 需要，Python 版不需要）
================================================================================

【适用】内网 Win7 SP1 上运行 wpf\build.bat 生成的 Excel表格拆分工具.exe

【外网下载】（仅打离线包时需要，内网不必上网）

  官方离线安装程序（约 120 MB）：
    文件名：ndp48-x86-x64-allos-enu.exe
    搜索：.NET Framework 4.8 offline installer
    或 Microsoft 下载页 “.NET Framework 4.8 Offline Installer”

【放置位置】

  redist\win7\ndp48\ndp48-x86-x64-allos-enu.exe

  然后运行仓库根目录「打包_Win7内网部署包.bat」，会一并打入部署包。

【内网安装】

  将 ndp48 目录随部署包拷入后，运行 win7_安装运行库.bat 时会自动检测并安装
  （需管理员；安装后可能需重启）。

【说明】

  - Python 打包的 exe 不依赖 .NET 4.8，可忽略本目录。
  - 若内网已通过组策略统一安装 .NET 4.8，无需再放本文件。
